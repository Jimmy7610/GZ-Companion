# Contextual Advisor (Milestone 8)

Status: **Implemented, pending human gameplay QA.**

## What this is

A small, ranked, explainable set of "what should I do next" suggestions, generated entirely from
real local data — never a hardcoded fake tip. There is no new top-level tab: Home's existing
"Vad ska jag göra?" button now opens this Advisor as an overlay on the Home tab.

## Architecture

- `advisor.AdvisorContext` — a plain, Minecraft-API-free snapshot of the real inputs: the Guide's
  current objective and completion state, the Settlement planner's chosen level range and derived
  missing-material count, an active Building plan's incomplete checklist count and display name,
  whether MarketWatch has local notes, and whether the client is currently connected to GameZone.
- `advisor.AdvisorEngine` — a pure, stateless rule evaluator (`generate(AdvisorContext)`). Each
  rule has a fixed priority so the same context always produces the same ordering
  (deterministic); at most 3 suggestions are returned; if nothing matches, one safe generic
  suggestion is returned instead of an empty list.
- `advisor.AdvisorContextBuilder` — the only class in this package allowed to touch
  `CompanionSession`/knowledge/storage; it reads the real, already-loaded Guide/Settlement/
  Building state and produces an `AdvisorContext`. Keeping this bridge separate from the pure
  engine is what makes `AdvisorEngineTest` able to test every rule deterministically without a
  live Minecraft client.
- `ui.tabs.HomeTabComponent` — clicking "Vad ska jag göra?" builds a context via
  `AdvisorContextBuilder.build(session)`, ranks it via `AdvisorEngine.generate(...)`, and renders
  it as an overlay: each suggestion shows **Vad** (title), **Varför** (reason), and **Nästa steg**,
  with an optional copy-only clipboard button when the suggestion names an already-verified
  GameZone command (e.g. `/marketwatch`). Nothing here executes a command or opens another tab
  automatically.

## Current rules (in priority order)

1. **Fortsätt guiden** — the Guide has a real next step and hasn't been completed.
2. **Samla material för nästa settlementnivå** — the player chose a Settlement current/target
   level range in Progression and at least one merged material requirement is still short.
3. **Bygg färdigt `<building>`** — the most recently created local Building plan with any
   incomplete checklist item.
4. **Kontrollera MarketWatch manuellt** — the player has local MarketWatch notes (wired once M9
   ships; the rule and its test already exist and pass with a synthetic context).
5. **Utforska GZ Companion** — the generic fallback, shown only when nothing else applies.

## Fair play and privacy

No suggestion is ever generated by scanning the world, reading hidden entities, or observing
anything the player hasn't legitimately already loaded into the Companion themselves. No command
is ever run automatically — every actionable suggestion is copy-to-clipboard only.
